# WarmupSafezone HSM UI results — 2026-08-30

## Production profile

All entries use HSM `Center` alignment, `Middle` vertical anchor, base text size 22, minimum line height 12, and a transparent 49-column `1em` tail on each physical row. The tail holds the visible text in the left safe lane without using unsupported edge alignment.

| Stable tag | X | Y | Text profile |
|---|---:|---:|---|
| `warmupsafezone.action-blocked` | -800 | 150 | one line, size 22 |
| `warmupsafezone.blocker` | -800 | 235 | title size 32 plus detail size 22 |
| `warmupsafezone.surface-drain` | -800 | 325 | one line, size 22 |

The EN/CN fixtures are `warmup-safezone-en.json` and `warmup-safezone-cn.json`. They deliberately render all three stable entries together. Runtime blocker and surface-drain geometry is normally mutually exclusive, so the composite is a stricter layout check; action-blocked may coexist with either.

## StatsBots coexistence gate

The reproducible `warmup-suite-en.json` and `warmup-suite-cn.json` fixtures combine the exact
WarmupSafezone entries with the exact entries from `StatsBots/tests/ui/statsbots-{en,cn}.json`
and `tests/ui/scpslbot-notice-{en,cn}.json`. This exercises all three runtime products together:
WarmupSafezone owns the upper-left bands at Y 150/235/325, StatsBots owns the lower-left bands at
Y 735/780/850, and SCPSLBot owns the bottom-centre warhead notice at X 0/Y 1040. All ten
language/background combinations passed with exit code 0, zero non-OK validation messages, and
zero layout issues.

Combined renders are saved as
`output/warmup-suite-{en,cn}-<background>.png`.
